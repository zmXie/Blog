Vue3 中新增了一系列函数，比如：ref、reactive、toRefs、setup 等等，那这些函数是如何工作的呢？

### ref

`ref` 将单一值包装为响应式数据，比如基础数据类型 String，Number，Boolean，还有一些简单对象和数组（没有嵌套）。虽然内部也兼容了 `reactive`，但是使用时最好区分，便于阅读。

```js
// 创建一个响应对象，将值包装在value属性中
function ref(initialValue) {
  let value = initialValue; // 存储实际值
  // 如果值是对象或数组，则代理该对象或数组，使对象属性也具有响应式
  if (Array.isArray(_value) || (typeof value === 'object' && value !== null)) {
    value = reactive(value);
  }
  // 创建一个对象，将值包装到value属性中，value是getter定义的属性，并添加setter函数来监听变化
  const refObject = {
    get value() {
      console.log(`Getting value: ${value}`);
      return value;
    },
    set value(newValue) {
      if (newValue !== value) {
        console.log(`Setting value: ${newValue}`);
        value = newValue; // 更新值
      }
    }
  };
  return refObject;
}
// 使用示例
const count = ref(0);
console.log(count.value); // Getting value: 0
count.value = 1; // Setting value: 1
```

### reactive

`reactive` 定义复杂对象和嵌套结构数组为响应式数据，`reactive`基于 proxy，对象中所有属性的变动都会被监听到。

### setup

`setup` 是一个特殊的钩子函数，专门用于组合式 API，该函数在组件实例创建之前执行一次。所有的响应式数据和方法都需要在`setup`中定义，并通过对象`return` 出去才能使用，包括生命周期钩子也需要在该函数中定义。

```vue
<script>
import { ref } from 'vue';
export default {
  setup() {
    const count = ref(0);
    function increment() {
      count.value++;
    }
    onMounted(() => {
      console.log('Component is mounted');
    });
    // 必须返回 count 和 increment，模板才能访问它们
    return {
      count,
      increment
    };
  }
};
</script>
```

- 在单文件组件中可以使用`<script setup>`编译时语法糖来简化书写，不再需要显示写`setup`函数以及`return`，在编译时会自动生成`setup`函数，并将其中定义的变量和方法`return`出去。

```vue
<script setup>
import { ref } from 'vue';
const count = ref(0);
function increment() {
  count.value++;
}
onMounted(() => {
  console.log('Component is mounted');
});
</script>
```
